X is a **publishing, analytics and DM** integration via the X API v2 (OAuth 2.0
with PKCE, auto-refreshing tokens).

<CardGroup cols={3}>
  <Card title="Publish" icon="feather">Text, images or video.</Card>
  <Card title="Analytics" icon="chart-simple">Account & per-tweet metrics.</Card>
  <Card title="DMs" icon="envelope">Synced on demand, sent from the inbox.</Card>
</CardGroup>

## Connect

OAuth 2.0 (PKCE) flow:

```bash
curl "https://api.plugkit.co/v1/connect/x?profileId=YOUR_PROFILE_ID" \
  -H "Authorization: Bearer sk_your_key"
```

Open the returned `authUrl` and approve. PlugKit runs the X app; there is
nothing to register on your side.

## Publish a tweet

X accepts **text only**, **1–4 images**, **or** a single video/GIF (media is
optional):

```bash
curl -X POST https://api.plugkit.co/v1/posts \
  -H "Authorization: Bearer sk_your_key" -H "Content-Type: application/json" \
  -d '{ "profileId": "PROFILE_ID", "accountIds": ["ACCOUNT_ID"],
        "content": "We just shipped 🚀", "mediaUrls": ["https://…/image.jpg"], "publishNow": true }'
```

The response includes the tweet's `platformPostId` and `platformPostUrl`.

## Analytics

X feeds the [analytics store](/guides/analytics) like the other platforms —
likes, replies, reposts and impressions per post — with two differences that
follow from X billing every API read.

<Warning>
  **Nothing is polled until you opt in.** Background analytics on an X account
  are off by default, per account:

  ```bash
  curl -X PATCH https://api.plugkit.co/v1/accounts/ACCOUNT_ID/x-billing \
    -H "Authorization: Bearer sk_your_key" -H "Content-Type: application/json" \
    -d '{ "analytics": true, "acknowledgeCost": true }'
  ```

  `acknowledgeCost` is required to turn it on: the call is refused without it,
  and the refusal carries the rate card so you can show it first. See
  [Plans & billing](/concepts/billing).
</Warning>

Once enabled:

- A post is refreshed **at most once a day**, whatever your plan. The hourly
  window other platforms get would cost $0.005 per post per hour.
- **Only posts published through PlugKit are tracked.** Listing your timeline to
  discover the others would be a billed read per page, forever, to find posts we
  already know about.
- Collection stops when your [spend cap](/concepts/billing) is reached.
  Publishing never does.

A **$20 monthly cap applies by default**, so this can't run away on its own.
Raise or lower it to fit:

```bash
curl -X POST https://api.plugkit.co/v1/billing/spend-cap \
  -H "Authorization: Bearer sk_your_key" -H "Content-Type: application/json" \
  -d '{ "capUsd": 20 }'
```

## Direct messages

X DMs land in the same [inbox](/guides/messaging) as the other platforms, with
three differences that come from X itself.

- **No webhook: DMs only arrive when you sync.** Run
  `POST /v1/inbox/conversations/sync?accountId=ACCOUNT_ID` (or the
  `sync_conversations` MCP tool). Nothing pulls X DMs in the background, and
  synced DMs don't fire `message.received`.
- **Each sync is billed per DM returned.** A sync reads up to the **last 200
  DMs from the past 30 days**, including ones already pulled, at $0.010 each —
  so **at most $2 per sync**. Syncing every few minutes adds up fast.
- **One-to-one only.** Group DMs are skipped, and conversations moved to X's
  encrypted chat may not be returned by the API.

Syncing is off by default, like analytics. Turn it on per account:

```bash
curl -X PATCH https://api.plugkit.co/v1/accounts/ACCOUNT_ID/x-billing \
  -H "Authorization: Bearer sk_your_key" -H "Content-Type: application/json" \
  -d '{ "inboxSync": true, "acknowledgeCost": true }'
```

Replies go out with the usual
`POST /v1/inbox/conversations/{id}/messages`, at $0.015 per DM. Text only:
attachments aren't supported, and buttons are written out as plain links.

<Note>
  Accounts connected before November 23, 2026 don't have the DM scopes.
  Reconnect them once to grant `dm.read` and `dm.write`; until then a sync
  returns a `403` that says so.
</Note>

## Pricing

X calls are re-billed at cost — $0.005 a read, $0.015 a post, **$0.200 for
a post containing a URL** (X's own pricing, roughly 13× a normal post), $0.010
per DM read and $0.015 per DM sent. Watch it with `GET /v1/usage`; see
[Plans & billing](/concepts/billing).

## Permissions

Scopes: `tweet.read`, `tweet.write`, `users.read`, `media.write`, `dm.read`,
`dm.write`, `offline.access` (for token refresh).
